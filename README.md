# Front-End Practice Portfolio

A small portfolio site that presents three front-end course assignments. The project pages are static reproductions built from course-provided briefs and visual assets; they are not client commissions and are not affiliated with the companies whose designs or marks appear in the study material.

## Projects

- **Responsive Blog & Article Pages** — two responsive content pages with reusable cards and viewport-specific images.
- **Responsive Real Estate Landing Page** — an image-led landing page with responsive sections and picture sources.
- **Responsive Search Results UI** — results and empty-state layouts. Search functionality is not implemented.

The showcased pages use Russian sample copy. The portfolio index is in English. The public copies have been cleaned of business contact details and source maps.

## Stack

HTML5, CSS, SCSS, responsive layouts, responsive images.

## Preview

Open `index.html` locally, or enable GitHub Pages for the repository root.
